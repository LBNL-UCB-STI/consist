1. Guiding Principles: Clean End State, Zero Split-Brain¶

Because v0.5 will not be deployed to production mid-stack between PR 1 and PR 4—and existing v0.4 databases can be migrated cleanly via consist migrate—we optimize strictly for the cleanest, fastest, least-risky end state rather than carrying v0.4 runtime compatibility shims:

  1. Subtractive In-Place Replacement (One Mental Model):
  2. Every PR upgrades an existing v0.4.2 seam in place and deletes superseded v0.4.2 code in the same PR (including deleting src/consist/core/schema_compat.py's legacy v0.2/v0.3 runtime backfill shims).
  3. Never introduce a second persistence class (StoreLedger beside DatabaseManager), a second output/archive engine (engine.seal / PendingOutput beside Tracker), a second run JSON format (store/manifest.py beside consist.json), or a second identity type (AdmissionIdentity beside Digest).
  4. Clean ~14-Table v0.5 Schema + Cold-Safe consist migrate (~350–450 LOC, Not 5,786 LOC):
  5. Avoid both v0.4 runtime ALTER TABLE shims and PR #316's 21-table over-normalization (artifact_location_event append logs + ROW_NUMBER() CTE views + anchor_promotion joins + Kind.HISTORICAL / consist promote).
  6. Keep config_facet, run_config_kv, artifact_facet, and artifact_kv as direct indexed DuckDB tables populated via executemany (zero wrapper views, zero query rewrites across queries.py/views.py/pivot_facets).
  7. Store a clean consist_schema(version=2, db_uid=...) header; opening a version=1 DB raises DatabaseMigrationRequired("Run 'consist migrate <db_path>'") (subclassing IncompatibleSchemaError) immediately with zero legacy fallback branches in runtime code.
  8. consist migrate <db_path> applies deterministic rules safe for both hot local workspaces and cold/temporarily unmounted HPC archives:
    • Artifact bytes exist on disk (under --mounts / --run-dir): compute the canonical v0.5 Digest via its real scheme driver (or, with --trust-v04-hashes for multi-TB archives, convert already-attested 64-hex v0.4 SHA-256 / manifest-v1 / logical_matrices hashes without re-reading multi-TB files while always re-hashing non-hex fast hashes), capture FileStat (racy=False when older than 2s), insert an 'active' artifact_location row, and—when all inputs of a run have valid v0.5 Digests—recompute the run's native v0.5 input_hash and signature (cacheable=True -> 100% live cache hits immediately, fixing B15).
    • Artifact bytes missing or archive currently unmounted: record digest = None (preserving legacy_v04_hash in artifact.meta), still insert all recovery_roots + container_uri into artifact_location keyed by artifact_id (digest IS NULL) so mounting the archive later immediately restores art.path and cold ViewFactory reads, and mark linked runs cacheable = False. Copy global_tables.* and custom SQL views intact.
  9. Clean End-State Public Contracts:
  10. Artifact.digest: Digest | None, Artifact.uri: str, Artifact.member: str | None: Canonical scheme-qualified identity (digest.scheme, digest.hex, str(digest) == "<scheme>:<hex>") and single primary URI + optional container member, replacing untyped Artifact.hash and split container_uri/table_path/array_path.
  11. First-Class BaseModel / SQLModel User Row Schemas Without ORM Coupling: Consist's internal provenance models (Artifact, Run, etc.) are pure dataclasses / Pydantic models with zero SQLModel(table=True) or SQLAlchemy Session execution, while user-defined tabular row schemas (Tracker(schemas=[Person]), dlt strict mode, ViewFactory, ibis_view, schema_stub) stay first-class via pure Pydantic model_fields introspection.
  12. Explicit, Zero-Surprise Step Parameter Binding:
    • Parameter type annotations always take precedence (def step(x: Artifact): -> Artifact with zero pre-step staging/hydration I/O; def step(x: Path): -> verified staged Path with zero DataFrame load; def step(x: pd.DataFrame): / GeoDataFrame / xr.Dataset / pa.Table -> loaded dataset via consist.load; output out: Path -> injected target Path for outputs={"out": ...}).
    • Unannotated input parameters def step(x): default to Artifact (zero eager pre-step I/O, fixing B17), unless the caller explicitly specifies ExecutionOptions(input_binding="paths" | "loaded").
  13. Strict Acyclic Downward Dependency DAG (Zero Hidden Back-Edges):
  14. Layer 1 — Leaf (consist.digest, consist.types, consist.protocols): Stdlib + optional Arrow/Pandas/HDF5 only; zero imports from consist.models.* or consist.core.*. Defines ArtifactResolver protocol + contextvars active-resolver hook (get_active_resolver / bind_active_resolver).
  15. Layer 2 — Value Models & Witnesses (consist.models.artifact, consist.models.run, consist.location): Frozen/plain value objects + FileStat/DirTreeStat witnesses. Zero imports of Tracker or DatabaseManager; zero live SQL/I/O inside data fields (uri, digest, member, meta) or JSON serialization. Convenience resolution methods (art.path, art.as_path(), art.ensure_local_path(), art.as_df(), art.accessibility()) delegate strictly via weakref/contextvar ArtifactResolver (art.with_resolver(...) via dataclasses.replace—zero object.__setattr__!).
  16. Layer 3 — Persistence (DatabaseManager in consist.core.persistence): One class owning the native duckdb.DuckDBPyConnection, schema DDL, indexed SQL queries, cursor tracking, and dlt connection borrowing.
  17. Layer 4 — Workflow & Surface (Tracker, Coupler, TrackerArchiveService, materialize.py, ViewFactory, cli.py, api.py).
  18. Hard Merge Gates on Every PR:
  19. scripts/benchmarks/metadata_hot_path_profile.py (20-in / 15-out warm miss & cache.hit.start_run) <= 1.0x of origin/main (<= 235 ms / <= 245 ms), plus sub-millisecond art.path, Coupler.set, and Ephemeral Mode Tracker().
  20. Clean-venv smoke test (uv venv with base consist only—no consist[git], pandas >= 3.0, Python 3.11 & 3.13).
  21. Architectural & hygiene gates: zero new circular dependencies, zero post-init object.__setattr__ / getattr / .__dict__.get hacks on domain/tracker state, and typing_extensions.Protocol + typing_extensions.runtime_checkable across all @runtime_checkable protocols in src/consist/.

Design & Implementation Blueprint¶

  1. Single Native Connection, Poison-Safe Re-Entrant Transactions & Subprocess Barrier (DatabaseManager):
  2. Own one duckdb.DuckDBPyConnection (duckdb.connect(str(db_path), read_only=read_only)) guarded by self._lock = threading.RLock() and self._cond = threading.Condition(self._lock) (_suspended: bool).
  3. Re-entrant transactions without SAVEPOINT (DuckDB does not support SQL SAVEPOINT): track _tx_depth: int = 0 and _tx_poisoned: bool = False under self._lock:
    • _tx_depth 0 -> 1 executes BEGIN TRANSACTION.
    • _tx_depth > 1 joins the active transaction on self.connection without issuing SQL; if an inner with db.transaction(): exits via exception, set _tx_poisoned = True and re-raise. Exiting depth 1 -> 0 checks _tx_poisoned: if poisoned (even if an outer caller caught the inner exception), execute ROLLBACK and raise TransactionAbortedError rather than silently committing partial state. Use SELECT checks or ON CONFLICT instead of try/catch write probes inside transactions.
  4. Cursor visibility & lifecycle:
    • When _tx_depth > 0, execute all queries directly on self.connection under self._lock so nested helpers see uncommitted writes and never trigger DuckDB MVCC write-write conflicts.
    • When _tx_depth == 0, relation_query() clones a tracked cursor registered in self._open_cursors so to_df(..., close=True), db.close(), and suspend_for_subprocesses() reliably close the underlying root cursor even when callers chain .limit() / .filter() (which return new DuckDBPyRelation wrappers in DuckDB 1.5.1).
  5. suspend_for_subprocesses(): sets _suspended = True, closes all tracked cursors in self._open_cursors, closes any cached Ibis cursor backend (TrackerIbisIntegration.close()), executes CHECKPOINT + closes self.connection, and blocks any concurrent thread attempting DB access on self._cond until resumed.
  6. Schema header check: on open, inspect consist_schema.version; if version == 1 (or legacy unversioned run table), raise DatabaseMigrationRequired("Database uses Consist v0.4 schema (version=1). Run 'consist migrate <db_path>'.") (subclassing IncompatibleSchemaError).
  7. Clean Native DuckDB Tables (Zero Wrapper Views):
  8. Create core tables via explicit DuckDB SQL DDL:
    • consist_schema(version INTEGER PRIMARY KEY, db_uid VARCHAR NOT NULL, updated_at TIMESTAMPTZ)
    • run (including cacheable BOOLEAN NOT NULL DEFAULT TRUE, meta JSON, tags JSON, stage VARCHAR, phase VARCHAR, facet_id VARCHAR, etc.)
    • artifact(id UUID PRIMARY KEY, key VARCHAR NOT NULL, uri VARCHAR NOT NULL, driver VARCHAR NOT NULL, digest VARCHAR, member VARCHAR, run_id VARCHAR, parent_artifact_id UUID, facet_id VARCHAR, meta JSON, created_at TIMESTAMPTZ) (mapped cleanly to/from Artifact.container_uri, table_path/array_path, and hash inside DatabaseManager until PR 2 upgrades the Artifact class; artifact_content table removed)
    • run_artifact_link(run_id VARCHAR NOT NULL, artifact_id UUID NOT NULL, direction VARCHAR NOT NULL, role VARCHAR NOT NULL, is_implicit BOOLEAN NOT NULL DEFAULT FALSE, PRIMARY KEY (run_id, artifact_id, direction, role))
    • config_facet, run_config_kv, artifact_facet, artifact_kv (direct indexed tables populated via executemany—zero wrapper views!)
    • run_binding_invocation, run_coupler_snapshot
    • artifact_schema, artifact_schema_field, artifact_schema_relation, consist_schema_links
    • activitysim / beam config cache tables created via explicit DuckDB DDL from Pydantic model_fields (eliminating SQLAlchemy Session in activitysim/config_adapter.py and beam/config_adapter.py).
  9. Packaging & Clean-Install Hardening (pyproject.toml):
  10. Declare "pytz>=2024.1" and "typing-extensions>=4.12" explicitly in [project].dependencies (retaining "sqlmodel>=0.0.31" for user-defined tabular row schemas).
  11. Ensure Tracker.start_run() degrades cleanly when optional consist[git] (gitpython) is not installed.
  12. Parameterized SQL Pushdown & Safe dlt / Ibis / CLI Connection Sharing:
  13. Rewrite find_matching_run (WHERE cacheable = TRUE ...), get_artifacts_for_run, get_output_artifacts_for_run, and find_runs (tags, scalar metadata normalizing numbers.Integral/numbers.Real so np.int64 never disables SQL LIMIT, limit/offset) into parameterized DuckDB SQL.
  14. Add Tracker.query_rows(sql, params=None, *, model=...) guarded by DuckDB's extract_statements() read-only SQL validator.
  15. with db.borrow_for_dlt() as conn:: raises RuntimeError if _tx_depth > 0, acquires self._lock, passes conn to dlt.destinations.duckdb(credentials=conn), and unconditionally executes SET search_path = 'main' in finally: so dlt's search_path = 'global_tables' mutation never breaks subsequent DatabaseManager queries.
  16. Open Tracker(..., read_only=True) on read-only CLI commands + extract holder PID on DuckDB lock conflicts (Option 4A); use CREATE OR REPLACE TEMP VIEW in ViewFactory.create_view() and ibis_view() when read_only=True; preserve consist_artifact_id IS NULL (consist_run_id fallback) across views.py, netcdf_views.py, spatial_views.py, and openmatrix_views.py.

  10. Post-dlt global_tables ingestion never overwrites art.digest or attaches a snake-cased SQL table hash as ctd1:sha256 (B8 fix); whole-table SQL sorting/hashing during dlt append is kept out of the hot path.
  11. Freeze the canonical v0.5 input_hash (hash of sorted (role, str(artifact.digest)) pairs) and signature = sha256(f"{code_hash}:{config_hash}:{input_hash}") in PR 2 so PR 3's consist migrate and PR 4's workflow orchestration share one invariant signature definition.

  6. Racy-Safe FileStat & DirTreeStat Witnesses (src/consist/location.py, ~350 LOC):
  7. Capture (size, mtime_ns, ctime_ns, ino, racy=abs(observed_at_ns - mtime_ns) < 2_000_000_000).

  12. ArtifactResolver (art.path, art.as_path(), art.ensure_local_path()), consist.load(), ViewFactory, and core/admission.py all call resolve_verified_local_path(artifact, tracker=...):

    • Checks witness freshness: if FRESH, returns immediately; if scratch was overwritten, missing, or a broken symlink, verifies digest or marks 'stale' and falls through automatically to verified archive locations (staging via stage_verified_source when ensure_local_path / materialization is requested).
  13. Safe Scratch Eviction in TrackerArchiveService:
    • archive_artifact(..., mode="move") / archive_run_outputs(..., mode="move") marks the moved workspace artifact_location row status='evicted' and upserts the destination archive location as status='active'.
    • Add compact (~40 LOC) tracker.evict_artifact(artifact, *, path=None) requiring explicit witness/digest match before unlink() (never deleting user-edited scratch files!) and requiring >= 1 surviving verified 'active' archive location or ingested global_tables table.
  14. Compact, Cold-Safe consist migrate <db_path> (~350–450 LOC):
  15. Reads v0.4 DB (version=1), builds v0.5 DB in <db_path>.v05.tmp, copies global_tables.* and custom SQL views intact, verifies CHECKPOINT succeeds (never swallowing errors before .wal cleanup!), atomically backs up <db_path> to <db_path>.v04.bak, and renames <db_path>.v05.tmp -> <db_path> (plus consist migrate undo <db_path>).

When an artifact resolves on disk under --mounts / --run-dir, compute its real v0.5 Digest + FileStat (or with --trust-v04-hashes, convert attested 64-hex v0.4 SHA-256 / manifest-v1 / logical_matrices hashes + os.stat() FileStat without re-reading multi-TB archives, while always re-hashing non-hex fast hashes).
